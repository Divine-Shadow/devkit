# Superseded: Codex Home Preservation

This completed plan is retained only as a decision-history tombstone. It is not
an operative custody rule.

Reuse a healthy Codex home when its identity, configuration, and auth pass
cheap checks. If that layer is broken or contaminated, preserve the operator
objective and protected external state, discard the home, and reconstruct it
through the canonical source-derived lifecycle. A task, home, worktree, or
station never owns the business objective.

The original plan remains available in Git history.
